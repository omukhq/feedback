# Feedback

Bug reports and ideas for [Omuk](https://omuk.dev)'s apps: airshot, Flume, AirBridge, Klipboard, PostVault and Gallery.

- **Found a bug?** [Report it](https://github.com/omukhq/feedback/issues/new?template=bug.yml).
- **Want something new?** [Suggest it](https://github.com/omukhq/feedback/issues/new?template=idea.yml).
- **Prefer to write privately?** Use the form at [omuk.dev/support](https://omuk.dev/support/).

Issues here are public. Do not put passwords, email contents or other private data in them.

The apps' source code is not public. This repo only holds the issues.
